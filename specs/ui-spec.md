# UI спецификация: Отслеживатель дедлайнов (MVP v2)

## Принципы
- Простота и скорость ввода.
- Четкая видимость ближайших дедлайнов.
- Минимум переключений, понятные статусы.
- Адаптивность: десктоп и мобильные.

## Навигация и структура
- Верхняя панель (Header):
  - Заголовок: «Дедлайны».
- Селект сортировки: «По дате», «По тегу (возр.)», «По тегу (убыв.)».
  - Переключатель представления (табы): «Активные», «Завершенные».
  - Кнопка «Теги» (открывает модалку управления тегами).

- Основная область:
  - В представлении «Активные»: форма добавления + список активных задач.
  - В представлении «Завершенные»: список завершенных задач.

- Модальные окна:
  - «Редактировать задачу».
  - «Управление тегами» (список тегов + формы добавления/редактирования).

## Контрольные элементы
Селект сортировки:
- Label: «Сортировка».
- Options: «По дате», «По тегу».
- Сохраняется в LocalStorage.

Переключатель представления:
- Табы: «Активные» | «Завершенные».
- Сохраняется в LocalStorage.

Кнопка «Теги»:
- Иконка «ярлык/тег». Открывает модалку.

## Форма добавления задачи (в «Активные»)
Поля:
- Текст задачи (input или textarea 1–3 строки).
  - Placeholder: «Что нужно сделать?»
  - Ограничение 200 символов, счетчик (например, 0/200).
- Дата (input type=date).
  - Label: «Дедлайн».
- Тег (select из списка тегов).
  - Label: «Тег».

Кнопка:
- «Добавить» (primary). Disabled, пока форма не валидна.

Валидация и подсказки:
- Текст обязателен.
- Дата обязателна; если дата в прошлом — показать предупреждение «Дата в прошлом», но разрешить добавление.
- Тег обязателен. Если нет тегов — показать инфоблок «Сначала создайте тег» с кнопкой «Открыть теги».

## Список задач (в обоих представлениях)
Формат строки/карточки:
- Левая часть: Текст задачи (перенос по словам).
- Центр/право: Бейдж даты (ДД.ММ.ГГГГ) и бейдж тега (цветной при наличии color у тега).
- Правая часть: кнопки действий.

Состояния строки:
- Обычная.
- Просроченная: дата и/или боковая метка красного цвета; tooltip «Дедлайн прошёл».
- Наведение: подсветка фона.
- Мобильная: кнопки действий в выпадающем меню «•••».

Действия:
- В «Активных»: «Готово» (✓), «Редактировать» (✎).
- В «Завершенных»: «Восстановить» (↩), «Редактировать» (✎). Дополнительно мелкий текст: «выполнено DD.MM.YYYY».

Пустые состояния:
- Активные: «Нет активных задач. Добавьте первую.»
- Завершенные: «Нет завершенных задач.»

Пагинация/прокрутка:
- Не требуется. Список скроллится, липкий хедер.

## Модалка «Редактировать задачу»
Поля:
- Текст задачи (как в форме добавления).
- Дата дедлайна (date).
- Тег (select).

Дополнительно:
- Переключатель статуса: «Активная» / «Выполненная» (не обязателен — действия «Готово/Восстановить» в списке достаточны; если включить — синхронизировать с completedAt).

Кнопки:
- «Сохранить» (primary), «Отмена» (secondary).

Ошибки:
- Подсветка невалидных полей, сообщения под ними.

## Модалка «Управление тегами»
Список тегов (таблица или список):
- Колонки: Имя | Приоритет | Цвет (опц.) | Действия.
- Действия: «Редактировать», «Удалить».

Добавление/редактирование тега:
- Поля: Имя (обязательно), Приоритет (целое число), Цвет (опц., input type=color или text).
- Проверка: имя уникально (без учета регистра — рекомендовано).
- При попытке удалить используемый тег: диалог «Тег используется N задачами» с единственной кнопкой «Ок».

Пустое состояние:
- «Тегов пока нет. Создайте первый тег.» + кнопка «Добавить тег».

## Цвета и стили (минимум)
- Фон: светлый (#fff), текст: #1f2937.
- Primary кнопка: синий (#2563eb), hover: #1d4ed8.
- Акцент ошибки/просрочки: красный (#dc2626).
- Бейдж тега: серый по умолчанию (#6b7280), если у тега задан color — использовать его с контрастным текстом.
- Разделители/границы: #e5e7eb.

## Типографика
- База: системные шрифты (ui-sans-serif stack), 14–16px.
- Заголовки: 18–20px полужирные.
- Бейджи: 12–13px, uppercase не требуется.

## Иконки
- Unicode/emoji или простые SVG встроенные в разметку: ✓, ✎, ↩, •••.

## Сетка и адаптив
- Контейнер до 800–960px шириной с паддингами.
- Мобильный (<640px):
  - Форма в одну колонку.
  - Карточка — стек: текст сверху, ниже бейджи/действия, кнопки в меню «•••».
- Десктоп: форма в строку, список в одну колонку.

## Доступность (UI)
- Видимая фокусировка, порядок табов логичный.
- Размер кликабельных зон ≥ 40×40 px на мобильном.
- Контраст ≥ AA.
- aria-label на кнопках с иконками: «Отметить как выполнено», «Редактировать», «Восстановить» и т.д.

## Микрокопирайтинг
- Кнопки: «Добавить», «Готово», «Редактировать», «Восстановить», «Сохранить», «Отмена», «Добавить тег».
- Подсказки ошибок: «Введите текст задачи», «Выберите дату», «Выберите тег», «Имя тега уже используется».

## Примеры состояний
- Активная просроченная задача: текст, дата красным бейджем, тег серый, кнопки «Готово»/«Редактировать».
- Завершенная: текст приглушен (opacity 0.7), бейдж «выполнено DD.MM.YYYY», кнопка «Восстановить».

## Анимации (минимум)
- Тонкая анимация появления/исчезновения строк (100–150мс, easing ease-out).
- Fade для модалок (200мс).
