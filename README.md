# Отслеживатель дедлайнов

Простое веб-приложение для личного учета задач и дедлайнов (MVP v2).
Работает в браузере без регистрации и бэкенда, сохраняет данные локально в LocalStorage.

## Возможности

- Добавление и редактирование задач: текст, дата дедлайна и тег.
- Просмотр активных и завершенных задач, отметка выполнения и восстановление.
- Сортировка по дате или приоритету тега (по возрастанию и убыванию).
- Настройка тегов: название, приоритет и необязательный цвет. Используемые теги нельзя удалить.
- Визуальное выделение просроченных задач.
- Сохранение задач, тегов, выбранной сортировки и представления между посещениями.

## Запуск

Сборка и установка зависимостей не нужны. Запустите статический HTTP-сервер из корня проекта, например с помощью Python 3:

```sh
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000) в современном браузере.
Используйте HTTP-сервер, а не открывайте `index.html` напрямую: приложение использует ES-модули.

## Использование

1. При необходимости создайте тег через кнопку «Теги».
2. В разделе «Активные» введите текст задачи (до 200 символов), выберите дату и тег, нажмите «Добавить».
3. Выберите удобную сортировку. Для сортировки по тегам порядок задается их числовым приоритетом.
4. Нажмите «Готово», чтобы завершить задачу. В разделе «Завершенные» ее можно восстановить.

Данные доступны только в текущем браузере и для текущего адреса сайта. Очистка данных сайта удалит сохраненные задачи. Синхронизация между устройствами и напоминания в MVP не предусмотрены.

- `styles.css` — стили интерфейса.
- `src/` — JavaScript-модули приложения.
- `specs/` — спецификации проекта:
  - [Продуктовая](specs/spec.md) — возможности, требования и сценарии.
  - [Техническая](specs/tech-spec.md) — архитектура, модель данных и хранение.
  - [Интерфейс](specs/ui-spec.md) — экраны, элементы управления и состояния.

Стек: HTML, CSS, JavaScript (ES Modules), LocalStorage. Без фреймворков.
